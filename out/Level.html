Class: Level

Level(endboss, enemies, clouds, backgroundObjects, collectables)

Represents a game level containing all enemies, clouds, background objects, collectables and coins.

Constructor

new Level(endboss, enemies, clouds, backgroundObjects, collectables)

Creates a new Level with the given game objects.
Parameters:
Name Type Description
endboss Endboss The endboss object of the level.
enemies Array.<MovableObject> Array of enemy objects in the level.
clouds Array.<Cloud> Array of cloud objects in the level.
backgroundObjects Array.<BackgroundObject> Array of background layer objects.
collectables Array.<CollectableObject> Array of bottles on the ground and coins in the level.
